# Astra — releases

Builds of the Astra panel for Adobe Premiere Pro and After Effects. This repository holds only the packaged releases and the update manifest; the source code is not published here.

- **Download:** see [Releases](https://github.com/edunascimentt/astra-releases/releases). Each release has `astra-<version>.zip` and its `.sha256`.
- **Update manifest:** [`updates.json`](updates.json) — installed panels read this file to find new versions.

Do not edit `updates.json` by hand; it is written by the publish script in the source repository.
